PROGRAM 6 - STUDENT REGISTRATION FORM (Node.js + Express.js)
=============================================================
Requirements : Node.js (https://nodejs.org)

Steps:
1. Open terminal inside folder "Program6-Student-Registration".
2. Install packages (only first time):   npm install
3. Start the server:                     node app.js
4. Open browser:  http://localhost:3000
5. Login ->  Username: admin   Password: 1234
6. Fill the registration form -> "Register Student".
7. Student details are displayed in a table. Use Logout to end the session.
8. Stop the server with Ctrl + C.
