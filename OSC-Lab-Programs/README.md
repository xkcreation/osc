# OSC Lab Programs (MCA - KGiSL Institute of Information Management)

Open Source Computing lab - all 8 programs in one repository.

| # | Program | Technology | Folder |
|---|---------|-----------|--------|
| 1 | Image Slideshow | HTML, CSS, JavaScript | `Program1-Image-Slideshow` |
| 2 | Electricity Bill Calculation | PHP | `Program2-Electricity-Bill` |
| 3 | Web-Based Feedback System | PHP, MySQL | `Program3-Feedback-System` |
| 4 | User Login Verification | PHP, MySQL, Sessions | `Program4-Login-System` |
| 5 | File Handling | Node.js | `Program5-File-Handling` |
| 6 | Student Registration Form | Node.js, Express.js | `Program6-Student-Registration` |
| 7 | Employee Information Portal | Node.js, Express.js, MongoDB | `Program7-Employee-Portal` |
| 8 | Git Basic Operations | Git, GitHub | `Program8-Git-Operations` |

Each folder contains a **HOW_TO_RUN.txt** with step-by-step instructions.
