PROGRAM 4 - USER LOGIN (PHP + MySQL + Sessions)
================================================
Requirements : XAMPP (Apache + MySQL)

Steps:
1. Copy folder "Program4-Login-System" into  C:\xampp\htdocs\
2. Start "Apache" and "MySQL" in XAMPP Control Panel.
3. Open http://localhost/phpmyadmin -> Import -> choose database.sql -> Go.
   (Creates database "login", table "user" and a test user.)
4. Open db.php and check the $port value:
      3306 = XAMPP default,   3308 = used in the lab record.
5. Open browser:  http://localhost/Program4-Login-System/login.php
6. Login with   Username: admin     Password: admin@123
7. Dashboard shows "Welcome, admin". Click Logout to destroy the session.


Create the database login and a table user with the columns username and password.
In db.php, connect to MySQL using the correct host, user, password, database and port.
In login.php, start the session and display a form for the username and password.
On submit, escape both inputs and search the user table for a row with the same username and password.
If exactly one row is found, store the username in $_SESSION and redirect to dashboard.php. Otherwise show the message "Invalid username or password".
In dashboard.php, check the session. If no user is logged in, redirect to login.php. Otherwise show a welcome message and a logout link.
In logout.php, destroy the session and redirect to login.php.
