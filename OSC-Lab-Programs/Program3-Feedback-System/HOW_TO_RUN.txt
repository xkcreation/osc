PROGRAM 3 - FEEDBACK SYSTEM (PHP + MySQL)
==========================================
Requirements : XAMPP (Apache + MySQL)

Steps:
1. Copy folder "Program3-Feedback-System" into  C:\xampp\htdocs\
2. Start "Apache" and "MySQL" in XAMPP Control Panel.
3. Open http://localhost/phpmyadmin -> click "Import" -> choose database.sql -> Go.
   (This creates database "feedbackdb" and table "feedback".)
4. If your MySQL has a password / different port, edit db.php.
5. Open browser:  http://localhost/Program3-Feedback-System/index.php
6. Fill Name, Email, Feedback -> Submit.
7. Click "View Data" to see all feedback in a table (view.php).


Create the database feedbackdb and a table feedback with the columns id, name, email and message.
In db.php, connect to MySQL with mysqli_connect() and stop with an error message if the connection fails.
In index.php, include db.php and display a form with the fields name, email and feedback.
When the form is submitted, escape the three inputs with mysqli_real_escape_string() and run an INSERT query.
Show an alert that the feedback was submitted successfully, or print the error if the query fails.
In view.php, run SELECT * FROM feedback and show every row in an HTML table, escaping the output with htmlspecialchars().
Add links to move between the form page and the view page.
