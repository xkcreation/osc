PROGRAM 1 - IMAGE SLIDESHOW (HTML + CSS + JavaScript)
======================================================
Requirements : Any web browser (Chrome / Edge / Firefox)

Steps:
1. Open this folder: Program1-Image-Slideshow
2. The "assets" folder has sample placeholder images (img1.jpg - img4.jpg).
   Replace them with your own images using the SAME file names.
3. Double-click index.html  (or right click -> Open with -> Browser).
4. The image changes automatically every 2 seconds and repeats.

(Optional) Run in VS Code: install "Live Server" extension -> right click
index.html -> "Open with Live Server".

Create index.html with one <img> element and link style.css and app.js to it.
In style.css, set the size of the image to 500 px x 500 px and centre it.
In app.js, store the paths of all the images in an array and set the starting index to 0.
Define a function that increases the index by 1, resets it to 0 after the last image and sets the image src to the image at that index.
Call the function repeatedly every 2000 milliseconds with setInterval().
Open index.html in a browser to see the slideshow.
